Machine Test Dashboard App

A simple React-based dashboard to manage delivery orders with live map tracking and order details display.

## 📌 Features

- Add delivery orders with name, area, driver, phone, ETA
- Unique auto-incrementing Order ID 
- Live map with a car icon showing the delivery location
- Click the map icon to highlight the order
- Order cards with status (e.g., Pending)
- Smooth and clean UI with responsive layout

## 🛠️ Tech Stack

- React.js
- Redux Toolkit
- Leaflet.js (for map)
- Tailwind CSS
- React Icons
